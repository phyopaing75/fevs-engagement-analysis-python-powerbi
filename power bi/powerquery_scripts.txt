FEVS 2024 - Power Query scripts (one per query)
In Power BI: Transform data > New Source > Blank Query > Advanced Editor > delete everything > paste ONE script > Done.
Then rename the query (right panel 'Name') exactly as shown in the QUERY NAME line.

======================================================================
QUERY NAME: fact_responses
======================================================================
let
    Source = Csv.Document(File.Contents(ModelFolder & "fact_responses.csv"), [Delimiter=",", Encoding=65001, QuoteStyle=QuoteStyle.Csv]),
    Promoted = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    Typed = Table.TransformColumnTypes(Promoted, {{"level1", type text}, {"group_key", Int64.Type}, {"question", type text}, {"answered_w", type number}, {"positive_w", type number}, {"negative_w", type number}, {"answered_n", Int64.Type}}, "en-US"),
    Renamed = Table.RenameColumns(Typed, {{"answered_w", "Weight answered"}, {"positive_w", "Weight positive"}, {"negative_w", "Weight negative"}, {"answered_n", "Answered (count)"}})
in
    Renamed
